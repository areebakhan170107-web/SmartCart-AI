# Raw data folder

Place original, permitted product CSV files here. Keep source files unchanged for traceability. Use store-specific filenames where known, such as amazon_electronics.csv or myntra_clothing.csv.

Do not put passwords, API keys, or private account exports here. Check each dataset's license and attribution rules before committing it. The pipeline will create cleaned outputs in data/processed/; those outputs are generated locally from the actual CSVs present.
